# Exhibit organisation profile

[`profile/README.md`](profile/README.md) is the page GitHub shows to everyone on [github.com/exhibitlabs](https://github.com/exhibitlabs). [`profile/assets/`](profile/assets) holds its banner for GitHub's light and dark themes. Members of the organisation see the member view from `exhibitlabs/.github-private`, which also links the repository.

Exhibit is the AI dispute agent for PayPal merchants: [exhibit.9to5code.com](https://exhibit.9to5code.com).
